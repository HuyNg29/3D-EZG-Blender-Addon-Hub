# Song ngữ Việt / Anh cho addon EZG

> v0.1 — 2026-09-30.

Mọi addon EZG có cặp nút **VI | EN** ở góc phải header của panel chính. Bấm ở addon nào thì
**mọi addon EZG đang bật** đổi theo, kể cả hub. Mặc định là tiếng Việt.

## 1. Cách nó chạy

- Ngôn ngữ lưu trong một file dùng chung: `<config Blender>/ezg_language.txt` (`vi` hoặc `en`).
  File thiếu hoặc hỏng thì coi như `vi`.
- Chuỗi **tĩnh** (`bl_label`, `bl_description`, `name`/`description`/`items` của property) được
  Blender chép lại lúc `register_class`, nên đổi ngôn ngữ = gỡ rồi đăng kí lại cả addon
  (`addon.unregister()` + `addon.register()`) trong một timer. Dữ liệu property nằm trong
  `.blend` / `userpref.blend` nên **không mất** — `tests/test_i18n.py` kiểm tra điều này.
- Chuỗi **động** (label vẽ trong `draw`, `report`, `poll_message_set`, lỗi...) gọi `tr()` lúc
  chạy nên đúng ngôn ngữ ngay.
- Extension không import chéo được nhau, nên mỗi addon mang một **bản chép giống hệt** của
  `tools/ezg_i18n.py` ở `addons/<pkg>/ezg_i18n.py`. Chỉ sửa bản gốc rồi chạy
  `tools/sync_i18n.py`; lint báo lỗi nếu bản chép lệch.

## 2. Dùng trong addon

```python
from . import ezg_i18n
from .ezg_i18n import tr

class FOO_OT_build(bpy.types.Operator):
    bl_idname = "foo.build"
    bl_label = tr("Tạo rig", "Build Rig")
    bl_description = tr("Sinh armature từ marker", "Generate the armature from the markers")

    size: IntProperty(name=tr("Cỡ", "Size"), description=tr("...", "..."))

    def execute(self, context):
        self.report({'INFO'}, tr("Đã tạo %d xương", "Created %d bones") % n)
        return {'FINISHED'}

class FOO_PT_main(bpy.types.Panel):
    ...
    def draw_header_preset(self, context):
        ezg_i18n.draw_toggle(self.layout, "foo")      # nút VI | EN

classes = (FOO_OT_build, FOO_PT_main, ezg_i18n.make_language_operator("foo"))

def register():
    ezg_i18n.register_classes(classes)       # = localize() + register_class cho từng class

def unregister():
    ezg_i18n.unregister_classes(classes)
```

- `tr(vi, en)` — **tham số đầu luôn là tiếng Việt**. Dùng được ở mọi chỗ, cả trong thân class.
- `make_language_operator(prefix)` tạo operator `<prefix>.ezg_language`. Mỗi addon một prefix
  riêng (dùng prefix operator sẵn có của addon), không dùng chung idname.
- Nút VI | EN đặt ở `draw_header_preset` của **panel chính** (panel cấp cao nhất, mỗi tab
  sidebar một cái). Không đặt ở panel con.
- Addon có việc chạy dài (modal, tiến trình nền) phải khai báo ở cấp module:
  `def ezg_i18n_busy(): return <đang chạy>`. Đang bận thì việc đổi ngôn ngữ tự hoãn tới khi xong
  — gỡ class của một modal đang chạy là Blender có thể crash.
- Class nào không đăng kí qua `register_classes` thì phải gọi `ezg_i18n.localize(cls)` ngay trước
  `bpy.utils.register_class(cls)`.
- Property gán thẳng lên kiểu Blender trong `register()` (`bpy.types.Scene.foo = ...`) dùng `tr()`
  bình thường — `register()` chạy lại mỗi lần đổi ngôn ngữ.
- `register()`/`unregister()` phải đối xứng: handler, timer, keymap, preview... gỡ ra hết và thêm
  lại được nhiều lần.

## 3. Quy tắc

1. Chuỗi có dấu tiếng Việt chỉ được nằm ở **tham số đầu của `tr()`**, trong `print()` hoặc trong
   comment/docstring.
2. Hai bản dịch phải có **cùng placeholder** (`%d`, `%s`, `{}`...), không thì một ngôn ngữ nổ
   `TypeError` lúc chạy.
3. Operator/Panel **không** được để docstring làm tooltip: Blender lấy docstring khi thiếu
   `bl_description`. Viết `bl_description = tr(...)`.
4. Chuỗi hiển thị giống hệt ở cả hai ngôn ngữ (tên sản phẩm như "Auto UV Palette", thuật ngữ
   Blender đứng một mình như "Armature") thì ghi `# i18n-skip` ở cuối dòng.
5. **Không dịch dữ liệu**: tên object/xương/vertex group/action, identifier của enum, key của
   custom property, tên file, chuỗi đem đi so sánh trong code. Chỉ dịch chữ người dùng đọc.
6. Enum có `items` là **callback**: danh sách trả về phải được giữ trong biến cấp module
   (cache), vì Blender không tự giữ tham chiếu tới chuỗi → chữ rác hoặc crash.
7. `print()` ra console giữ nguyên, không cần `tr()`.

## 4. Văn phong

**Tiếng Việt** — có dấu, dạng NFC, bỏ dấu kiểu cũ như phần còn lại của repo: *xoá, tuỳ, hoà,
khoá, thuỷ*. Giữ nguyên tiếng Anh cho thuật ngữ đúng như chữ hiện trong Blender để artist tìm
được: Armature, Action, Mesh, Object Mode, Pose Mode, Edit Mode, Rest Position, Weight Paint,
Vertex Group, Modifier, UV, NLA, Keyframe, Collection, Material, Texture, FBX, rig, marker,
bind, weight, retarget, snapshot, backup, profile. Viết "addon" (không gạch nối).

**English** — câu ngắn kiểu giao diện Blender: động từ đứng đầu cho nút ("Build Rig"),
Title Case cho nhãn nút/panel, câu thường có dấu chấm cho thông báo. Viết "add-on" như Blender.

| Tuỳ chọn | Options |
| Cài đặt | Settings |
| Trạng thái | Status |

| Tạo | Create / Build |
| Xoá | Delete / Remove / Clear |
| Thêm | Add |
| Áp dụng | Apply |
| Đặt lại | Reset |
| Tải lại | Reload / Refresh |
| Quét lại | Rescan |
| Duyệt | Browse |
| Thư mục | Folder |
| Lật gương | Mirror |
| Xương / bộ xương | Bone / skeleton |

| Không tìm thấy ... | ... not found |

## 5. Kiểm tra

```powershell
# Lint tĩnh, vài giây, không cần mở Blender:
& "D:\AppInstall\Steam\steamapps\common\Blender\4.5\python\bin\python.exe" tools\i18n_lint.py ezg_deco_namer

# Runtime cho một addon (bật addon, bấm EN/VI, soát chữ sót + dữ liệu):
$env:EZG_I18N_ONLY = "ezg_deco_namer"; .\tools\run_tests.ps1 -Only test_i18n; Remove-Item Env:\EZG_I18N_ONLY
```

Test runtime chỉ soát được nhánh `draw` mà context của test đi tới; nhánh cần object đang chọn,
area... do lint tĩnh lo. Muốn chắc chắn bằng mắt thì chụp panel thật (xem memory
`chup-giao-dien-blender`).

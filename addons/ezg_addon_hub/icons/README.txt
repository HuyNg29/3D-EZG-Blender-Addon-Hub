Logo EZG cho hub
================

Tha mot file PNG ten chinh xac la:

    ezg_logo.png

vao thu muc nay, la moi addon thuoc kho EZG se hien dung logo do trong danh
sach thay cho icon co san cua Blender.

Khuyen nghi:
  - Vuong, 32x32 hoac 64x64 pixel
  - Nen trong suot (alpha)
  - Hinh don gian, ro net o kich thuoc rat nho — icon trong danh sach chi cao
    bang mot dong chu

Khong co file thi hub tu dung lai icon co san (mac dinh la 'PACKAGE'), khong
bao loi gi. Doi icon co san o bien GROUP_ICON trong ui.py.

Sau khi them file phai bump version trong blender_manifest.toml roi push, nhu
moi thay doi khac — neu khong Blender se khong thay co ban moi.
